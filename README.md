# Quantiva — Sales Forecasting Web Application

Quantiva is a machine-learning-based sales forecasting application designed to analyze historical sales data, visualize trends, and generate future sales predictions.

## Features

* **CSV Data Upload:** Upload sales datasets for analysis.
* **Sales Forecasting:** Predict future sales using a machine learning model.
* **Data Visualization:** Explore historical sales and forecast trends through charts.
* **Forecast Reports:** View predictions and sales insights.
* **User Authentication:** User registration and login functionality.
* **Backend API:** Connect the frontend with forecasting and user-management services.

## Technology Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Node.js, Express.js
* **Machine Learning:** Python, scikit-learn and XGBoost, where implemented
* **Database:** MongoDB, if configured

## Project Structure

```text
sales_forecasting/
├── backend/
│   ├── config/
│   ├── controllers/
│   ├── middleware/
│   ├── ml/
│   ├── models/
│   ├── routes/
│   └── server.js
├── src/
│   ├── frontend/
│   ├── lib/
│   └── main.tsx
├── index.html
├── package.json
├── package-lock.json
└── vite.config.ts
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jignalgamit/Quantiva-Sales-Forecasting.git
cd Quantiva-Sales-Forecasting
```

### 2. Install frontend dependencies

```bash
npm install
```

### 3. Start the frontend

```bash
npm run dev
```

### 4. Configure the backend

Navigate to the backend directory, install its dependencies, and configure the required environment variables according to the project configuration.

```bash
cd backend
npm install
```

Start the backend using the appropriate script defined in `backend/package.json`.

### 5. Configure the machine learning environment

Install the Python dependencies listed in `backend/ml/requirements.txt` and configure the model service as required.
